# 📊 Datasets

## Purpose

This directory is the designated location for the **histopathology image dataset** used for model training, validation, and testing.

## Dataset: LC25000

**Full Name**: Lung and Colon Cancer Histopathological Image Dataset

| Property | Value |
|---|---|
| **Source** | [Kaggle — LC25000](https://www.kaggle.com/datasets/andrewmvd/lung-and-colon-cancer-histopathological-images) |
| **Total Images** | 25,000 |
| **Colon Images** | 10,000 (used for this project) |
| **Classes** | 2 (colon_aca, colon_n) |
| **Images per Class** | 5,000 |
| **Image Size** | 768 × 768 pixels |
| **Format** | JPEG |
| **Color Space** | RGB |

## Data Split Strategy

| Split | Percentage | Images |
|---|---|---|
| Training | 70% | 7,000 |
| Validation | 15% | 1,500 |
| Testing | 15% | 1,500 |

## How to Set Up

1. Download the dataset from [Kaggle](https://www.kaggle.com/datasets/andrewmvd/lung-and-colon-cancer-histopathological-images).
2. Extract only the **colon** subset (`colon_image_sets/`).
3. Place the extracted folder inside this `datasets/` directory.
4. Run the train/test split script:
   ```bash
   python scripts/split_dataset.py
   ```

## Storage Policy

- **This directory is excluded from Git tracking** (dataset is ~1.2 GB).
- Dataset must be downloaded independently by each developer.
- Do not commit image files to the repository.
